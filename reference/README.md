# Agent Name Service - Reference Materials

This directory contains reference materials, specifications, and research documentation for the Agent Name Service (ANS) project.

## Directory Structure

### 📋 [specifications/](./specifications/)
Contains detailed specifications and standards related to ANS:
- Protocol specifications (A2A, MCP, ACP)
- Naming conventions and schemas
- API specifications
- Data models and schemas

### 🔒 [security/](./security/)
Security-related documentation:
- Threat models and security analysis
- PKI certificate management
- Best practices for secure agent registration
- Vulnerability assessments

### 💡 [use-cases/](./use-cases/)
Detailed use case examples and scenarios:
- Multi-agent system implementations
- Marketplace integrations
- IoT applications
- Enterprise deployment patterns

### 🔌 [protocols/](./protocols/)
Protocol-specific documentation:
- Agent-to-Agent (A2A) protocol details
- Model Context Protocol (MCP) integration
- Agent Communication Protocol (ACP) specifications
- Protocol adapter implementations

## How to Use This Reference

1. **For Implementation**: Start with `specifications/` to understand the technical requirements
2. **For Security**: Review `security/` before deploying in production
3. **For Integration**: Check `use-cases/` for examples relevant to your scenario
4. **For Protocol Support**: See `protocols/` for protocol-specific integration details
